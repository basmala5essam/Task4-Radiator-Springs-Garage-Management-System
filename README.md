# Task4-Radiator-Springs-Garage-Management-System
MIA Training '27 OOP Task 4
## Overview
The Garage Management System is a C++ console application developed using Object-Oriented Programming (OOP) principles. It allows users to manage different types of vehicles in a racing garage by performing operations such as checking in cars, updating their information, searching, and generating reports.

The system supports two vehicle types:
- Racer
- Support Vehicle

Each vehicle calculates its performance score differently using polymorphism.

---

## Features

- Check in a new car
- View all registered cars
- Update car information (Tune-Up)
- Remove (Retire) a car
- Search for a car by its number
- Generate a garage report
- Calculate performance scores automatically
